# Reflection on AI Use

AI was used as a support tool, not as a replacement for my own work. I mainly used it to explain concepts, help troubleshoot problems, and assist with workflow-related tasks. This fits the allowed use of AI in the assignment, especially for brainstorming, explaining technical concepts, and debugging support.

A deliberate choice was to use AI for understanding and direction rather than for submitting finished code. When I received suggestions, I tested them, evaluated whether they suited the project, and adjusted them before using them. This was especially useful when working with Git, debugging, and checking how CSS and JavaScript functions should be used.

One useful example was using ChatGPT to understand Git commands during branch, merge, and conflict situations. This helped me make decisions about how to continue the workflow, while also learning more about version control in practice.

The main learning outcome from using AI was improved understanding of technical concepts and development workflow. It helped me become more confident in debugging, using Git, documenting code, and making informed implementation choices without depending on AI to produce the final solution.
